# مهجة · كوفي مختص

موقع تعريفي عربي (RTL) لمقهى **مهجة** في حي السلام بالرياض.

## المعلومات
- **الاسم:** مهجة (Muhjah Cafe)
- **التصنيف:** كوفي مختص (Specialty Coffee)
- **المدينة:** الرياض · حي السلام
- **التقييم:** 4.7 على خرائط قوقل (1,100 تقييم)
- **الجوال:** 0564689536 · **واتساب:** 966564689536
- **الموقع:** [خرائط قوقل](https://www.google.com/maps/search/?api=1&query=Muhjah%20Cafe%20Riyadh)

## لماذا اخترنا هذا النشاط
مقهى مختص بهوية بصرية مميزة وتقييم عالٍ (4.7) من أكثر من ألف زائر، لكنه بلا موقع إلكتروني يعكس دفء تجربته. اسم "مهجة" (القلب/الروح) منح المشروع اتجاهاً تصميمياً واضحاً.

## فكرة التصميم — "دفء بروح"
لوحة ألوان قهوية دافئة: بُنّي إسبريسو غني + كهرماني/عسلي + كريمي. خط العناوين **El Messiri** وخط النصوص **Tajawal**. أجواء حميمة تعكس معنى الاسم، مع صور حقيقية للمقهى وفنجان القهوة والجلسات الداخلية.

## التقنية
- HTML/CSS/JS خام (Vanilla) بدون أي خطوة بناء — يعمل مباشرة على GitHub Pages.
- بدون مكتبات ثقيلة. أيقونات SVG inline. خطوط قوقل عبر preconnect + display=swap.
- وصولية: تباين ≥ 4.5:1، HTML سيمانتيك، focus-visible، aria-labels، دعم prefers-reduced-motion.

## حالة الـ Backend
**غير مربوط بخادم.** نموذج الطلب تجريبي: يتحقق من المدخلات، يحفظ نسخة في `localStorage`، ثم يفتح محادثة واتساب جاهزة برسالة الطلب. لا يوجد نظام دفع أو قاعدة بيانات.

## مصدر الصور
صور حقيقية من ملف المقهى على خرائط قوقل، تمّت مراجعتها وتنقيتها (استُبعدت لوحات الأسعار والصور غير الواضحة). الملفات في `assets/img/`.

## التشغيل محلياً
```bash
cd muhjah-cafe
python3 -m http.server 8080
# افتح http://localhost:8080
```

## الاختبارات
Playwright في `tests/site.spec.ts` (8 اختبارات): RTL، عنوان الصفحة، التقييم، alt للصور، قائمة الجوال ملء الشاشة، عدم وجود تمرير أفقي عند 390px، تحقق النموذج وبناء رابط wa.me + localStorage، واللايتبوكس.
```bash
npm install -D @playwright/test
npx playwright install
npx playwright test
```
